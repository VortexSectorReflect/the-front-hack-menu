## 🧩 About

**The Front Companion** is a curated list of The Front open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource viewer, map markers
- **Quality-of-Life Helpers** — loot tracker, crafting notes, base layout planner
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Resource Tracker — monitor gathered materials in single-player
- Map Markers — annotate points of interest on the map
- Loot Notes — record and review loot locations
- Time Controls — adjust day and night cycle pacing for study

### Wallhack
- Item Catalog — browse crafting recipes and components
- Base Layout Notes — organize building plans
- HUD Tweaks — improved visibility for status bars

### Aimbot
- Practice Mode Notes — segment study of base builds
- Build Planner — manually plan structures before placing
- Crafting Buffer Notes — chain complex recipes in the editor
